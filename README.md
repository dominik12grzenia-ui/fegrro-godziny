# FeGrro Godziny

System rejestracji godzin pracy dla firm budowlanych.

- Backend: FastAPI + MongoDB
- Frontend: React + Tailwind + shadcn/ui
- Deploy: Render (backend) + Vercel (frontend) + MongoDB Atlas
- Domena: godziny.fegrro.pl

## Funkcje

- Logowanie admina i rejestracja brygadzistów
- Tabela godzin z edycją inline
- Przypisywanie pracowników do budów
- Synchronizacja z Excel na OneDrive
- Zaliczki, kary, nieobecności
- Mapa budów (Google Maps)
- Publiczne linki dla pracowników
- PWA (instalacja na ekranie głównym)
- **Zakładka SPRZĘT** — ewidencja narzędzi z przypisaniem do pracownika/budowy
